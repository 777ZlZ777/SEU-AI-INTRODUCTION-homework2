## 1 任务

课程给的题目是：对任意自然数 `n`，都存在素数 `p > n`，即 Euclid 定理。难点不在结论本身，而在于要求每一步都由计算机检查通过——不接受"看起来像证明"的文字。

## 2 AI 做了三件事

**① 搭环境。** 本机原本没有 Lean，AI 比较了 GitHub 直连、国内镜像等路线，用分段并发把 594 MB 的工具链拉下来，装好 Lean 4.35.0 并建了 lake 工程。

**② 写证明。** 产出 105 行 Lean 代码（`Euclid.lean`）。因未安装 Mathlib，阶乘 `fac`、整除引理 `dvd_fac`、素数谓词 `Prime`、素因子存在性 `exists_prime_dvd` 全部从零构造。

**③ 跑验证。** `lake build` 通过；用 `#print axioms` 复查依赖，只有 `propext`、`Classical.choice`、`Quot.sound` 三条标准公理，没有任何 `sorry` 占位。

## 3 证明骨架

取 `m = n! + 1 > 1`，由素因子存在性取它的素因子 `p`。若 `p ≤ n`，则 `p` 整除 `n!`；又 `p` 整除 `n!+1`，故 `p` 整除两者之差 `1`，于是 `p = 1`，与素数定义 `p ≥ 2` 矛盾。因此 `p > n`。

```lean
theorem exists_prime_gt (n : Nat) : ∃ p, Prime p ∧ n < p := by
  obtain ⟨p, hp, hpdvd⟩ := exists_prime_dvd (fac n + 1) hm
  refine ⟨p, hp, Nat.lt_of_not_ge ?_⟩
  have hpdvdfac : p ∣ fac n := dvd_fac (by omega) hlen
    have hsub : p ∣ (fac n + 1) - fac n := Nat.dvd_sub hpdvd hpdvdfac
  have hp1 : p = 1 := Nat.eq_one_of_dvd_one hone
  omega
```

> 以上为 `Euclid.lean` 第 82–99 行的节选，逐字取自源码。

## 4 AI 犯的两个错，以及为什么要验证

**错误一**：AI 一开始给出了"√2 无理"的证明，收尾那一步是编的，逻辑并不闭合。若只看文字，这段"证明"显得非常专业。

**错误二**：AI 用了 `push_neg` 和 `by_contra` 两个 tactic，它们属于 Mathlib，Lean 核心库并没有。编译器报 `unknown tactic`，AI 才改成手写的 `Classical.not_forall` 与 `by_cases`。

> 这说明 AI 的"自信"和"正确"并不是一回事；形式化验证的价值，就是把这种差距变成一条可以被机器否定的证据。

## 5 反思

这次作业里，AI 负责"写"和"查"，我负责"判断"。真正省时间的不是让 AI 直接给答案，而是让它把答案变成能被机器否定的东西。对初学者来说，编译器的报错比批注更即时，也更不给人侥幸的余地。
